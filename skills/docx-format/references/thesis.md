# Thesis and academic manuscripts

Identify the institution, degree/article type, template version and intended
Word/WPS environment. Keep written institutional requirements distinct from
sample formatting. Do not apply one school's values to another manuscript.

Map cover, declarations, Chinese/English abstracts, keywords, TOC, chapters,
references, acknowledgements and appendices. Preserve cover and signature
regions until their fields and layout are understood. A metadata value that is
missing is not permission to invent it.

Use reusable heading styles already present when possible. Agent assignments
can correct paragraph roles, while a `paragraph.style_id` rule can bind an
existing style with native property revisions. Do not strip manual numbering
or renumber citations as an incidental formatting step.

## Special elements

- Equations: preserve OMML, OLE and image representations. A scoped paragraph
  override can adjust surrounding alignment/spacing without replacing the math
  object. Reconstructing old equation content is a separately reviewed action.
- Footnotes/endnotes: inspect their stories and body references together; keep
  IDs, separators and references. Role rules may format ordinary note text.
- Captions: identify the associated figure/table/equation, placement and
  numbering scheme. Existing SEQ/REF/PAGEREF fields remain intact by default.
- Figures: preserve original media, crop, wrap, anchor and grouping. Avoid
  fixed line heights that clip inline objects. Use a scoped paragraph rule
  rather than resetting all drawing properties.
- Citation managers: retain fields and hyperlinks. Typography changes do not
  authorize replacing Zotero/EndNote fields with plain text or reordering entries.
- Wide tables: retain landscape sections and verify repeating headers, page
  breaks, notes and margins; use the three-line-table guide only for data tables.

## Ordering

Resolve section boundaries and heading roles before numbering/TOC work. Set
page geometry and page-number policy, create/retain real fields, then update
them in the intended editor and recheck pagination. Front matter does not
universally use Roman numerals; it follows the confirmed institutional rule.

Proof should include content/object invariants plus views of each distinct
region. A successful abstract page does not validate the cover, formula pages,
landscape sections or bibliography. See `verification.md`.
